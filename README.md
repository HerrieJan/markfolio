# Markfolio

ローカルのドキュメントを閲覧・編集するデスクトップアプリです。  
Markdown を中心に、Mermaid / BPMN / draw.io も表示できます。

Built with **Tauri 2 + React + TypeScript + Vite**.

## なにができるか

- **読む** … Markdown（GFM）、テキスト、BPMN、draw.io  
- **書く** … `.md` / `.txt` を分割ライブプレビュー付きで編集し、`Ctrl+S` で保存  
- **図を見る** … Mermaid・BPMN の拡大表示、パン / ズーム  
- **探す** … ファイルツリー、名前・パス・本文検索  
- **開く** … `ファイル → フォルダーを開く`、またはファイル/フォルダのドラッグ＆ドロップ  
- **見やすく** … ライト / ダークテーマ、サイドバーの表示切替  

## アプリの使い方（要約）

1. 起動後、左ツリーからファイルを選ぶ（初期は同梱サンプル `docs` のことが多い）  
2. 自分の資料を見るときは **ファイル → フォルダーを開く**、またはフォルダをウィンドウへドロップ  
3. Markdown / テキストは右上の **閲覧 / 編集 / 分割** で編集（開いたときの既定は分割）  
4. 保存は **Ctrl+S**。未保存はファイル名の横に `•`  
5. 図は右上の拡大アイコンでフルスクリーン。Shift+ドラッグでパン、ホイールでズーム  

操作の詳細・対応形式・ショートカットは、アプリ内ドキュメントを参照してください。

- [`public/docs/README.md`](public/docs/README.md) … 概要とサンプル案内  
- [`public/docs/getting-started.md`](public/docs/getting-started.md) … 使い方ガイド  

アプリ起動後にツリーから同じファイルを開いても読めます。

## 開発

```bash
npm install
npm run tauri:dev
```

フロントだけ確認する場合:

```bash
npm run dev
```

※ ブラウザのみの起動ではファイル保存はできません。保存確認は `tauri:dev` かビルド版で行ってください。

### ビルド

```bash
npm run tauri:build
```

成果物: `src-tauri/target/release/bundle/`

## 今後の改善案

小さなローカル docs アプリとして、次を足すと効きやすいです（優先度の高い順）。

### すぐ効く改善

1. **アウトライン（見出しジャンプ）** … Markdown の見出し一覧から本文へジャンプ  
2. **未保存の扱い強化** … 一時バックアップや「前回の下書きを復元」  
3. **最近使ったフォルダ** … 既に保存している `recent_folders` をメニュー／起動画面に表示  
4. **相対リンク・画像** … `./foo.md` や画像パスを docs ルート基準で開けるようにする  
5. **保存フィードバック** … 「保存しました」などの短いトースト表示  

### あると嬉しい機能

6. **エクスポート** … 開いている Markdown → PDF / HTML  
7. **差分表示** … ディスク上のファイルとエディタ内容の簡易 diff（外部変更の検知にも）  
8. **印刷向けスタイル** … 閲覧モードの `Ctrl+P` 用 CSS  
9. **フォントサイズ / 折り返し** … 編集エリアの文字サイズと wrap 切替  
10. **BPMN / draw.io を外部で開く** … アプリ内編集はせず、既定アプリで開くボタン  

### 品質・完成度

11. **大きなフォルダの進捗表示** … 読み込み中のプログレス  
12. **draw.io のオフライン対応** … ローカルビューア、またはオンライン必須であることの明示強化  
13. **検索 UX** … ヒット件数、本文ヒット抜粋、次の結果へ移動  
14. **アイコン / About / バージョン表示** … インストーラまわりの仕上げ  
15. **自動テスト** … 保存・未保存警告・フォルダ解決などの薄いテスト  

### やらない方がよいこと（この規模では）

- クラウド同期・アカウント・リアルタイム共同編集  
- フル IDE 級の補完やプラグイン市場  
- アプリ内 BPMN モデラー（重い・別アプリ向き）  

**着手のおすすめ順:** アウトライン → 最近のフォルダ → 相対リンク/画像 → 保存トースト
