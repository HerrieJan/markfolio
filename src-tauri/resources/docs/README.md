# Markfolio サンプルドキュメント

Markfolio へようこそ。このフォルダは、アプリ同梱のサンプルドキュメントです。  
左のツリーからファイルを選ぶと、すぐに閲覧・編集の動作を試せます。

## Markfolio とは

ローカルにあるドキュメントを開いて読む・書くためのデスクトップアプリです。

- Markdown をきれいに表示し、その場で編集できる  
- Mermaid / BPMN / draw.io の図をアプリ内で確認できる  
- フォルダ単位で資料を切り替えられる  

社内仕様書、手順書、設計メモ、プロセス図などを、ブラウザや重いツールを起動せずに扱う用途を想定しています。

## 主な機能

| カテゴリ | 内容 |
|----------|------|
| 閲覧 | Markdown（GFM）、テキスト、BPMN、draw.io |
| 編集 | `.md` / `.txt` の編集、分割ライブプレビュー、保存（`Ctrl+S`） |
| 図 | Mermaid・BPMN の表示、フルスクリーン、パン / ズーム |
| ナビ | ファイルツリー、パンくず、サイドバー表示切替 |
| 検索 | ファイル名・パス・本文 |
| フォルダ | メニューで開く / ドラッグ＆ドロップ |
| 見た目 | ライト / ダークテーマ |

詳しい操作手順は **[使い方（getting-started）](./getting-started.md)** を読んでください。

## このサンプルの構成


### おすすめの見かた

1. まず [使い方](./getting-started.md) で操作を確認する  
2. [図の例](./examples/mermaid/diagram-examples.md) で Mermaid の見え方を試す  
3. `examples/bpmn/` の `.bpmn` を開いてプロセス図を見る  
4. 使い方ページを **分割** モードで開き、文言を少し書き換えてプレビューと保存を試す  

## 編集を試すときのヒント

- `.md` を開くと既定で「分割」になります（左：編集、右：プレビュー）  
- パンくず右の **閲覧 / 編集 / 分割** でレイアウトを変えられます  
- 未保存はファイル名の横の `•` で分かります  
- BPMN と draw.io は閲覧専用です
