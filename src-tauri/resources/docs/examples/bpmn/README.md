# BPMN サンプルファイル

このディレクトリには、BPMN (Business Process Model and Notation) のサンプルファイルが含まれています。

## サンプルファイル

### 基本サンプル

#### [simple-process.bpmn](./simple-process.bpmn)

基本的な承認プロセスのサンプルです。

**プロセスの流れ:**

1. 申請を開始
2. 上司が承認
3. 承認された場合は処理を実行
4. 却下された場合は終了

**学べる要素:**

- 基本的なタスク
- 排他ゲートウェイ（条件分岐）
- シーケンスフロー

#### [swimlane-process.bpmn](./swimlane-process.bpmn)

複数の担当者（プール/レーン）による協調作業のサンプルです。

**プロセスの流れ:**

1. 申請者が申請を作成
2. 承認者が申請を確認
3. 承認者が承認または却下
4. 承認の場合、実行者が処理を実行
5. 申請者に結果を通知

**学べる要素:**

- スイムレーン（プール/レーン）
- メッセージフロー
- 複数の参加者による協調作業

### 高度なサンプル

#### [complex-swimlane-process.bpmn](./complex-swimlane-process.bpmn)

3つのレーン（社員、マネージャー、経理部門）による経費申請プロセスのサンプルです。

**プロセスの流れ:**

1. 社員が経費申請書を作成
2. マネージャーが申請内容を確認
3. 承認の場合、経理部門が支払処理を実行
4. 差戻しの場合、社員が再申請
5. 経理部門で並列処理（帳簿記録と完了通知）

**学べる要素:**

- 3つのレーンによる複雑なフロー
- バウンダリイベント（差戻し処理）
- 並列ゲートウェイ
- 複数のメッセージフロー

#### [colored-process.bpmn](./colored-process.bpmn)

色付きのBPMN図のサンプルです。プロセスの種類やステータスを色で区別できます。

**プロセスの流れ:**

1. 注文を受け付け（緑：開始）
2. 注文を検証（青：入力チェック）
3. 有効性を判断（黄：分岐点）
4. 有効な場合、注文処理（緑）→ 商品発送（紫）
5. 無効な場合、注文却下（赤）
6. 通知送信（オレンジ）

**学べる要素:**

- BPMNの色付け（bpmn.io拡張機能）
- 視覚的な区別による可読性向上
- カラーコーディングのベストプラクティス

#### [parallel-gateway-process.bpmn](./parallel-gateway-process.bpmn)

並列ゲートウェイを使用した商品注文プロセスのサンプルです。複数の処理を同時に実行します。

**プロセスの流れ:**

1. 注文受付
2. **並列処理開始**: 決済処理、在庫確認、顧客情報確認を同時実行
3. **並列処理結合**: すべての処理が完了するまで待機
4. 注文確定
5. **2段目の並列処理**: 梱包と配送伝票作成を同時実行
6. 発送、顧客通知

**学べる要素:**

- 並列ゲートウェイ（Fork/Join）
- 複数の並列処理の組み合わせ
- 同期処理と非同期処理の制御

#### [event-subprocess-process.bpmn](./event-subprocess-process.bpmn)

イベントサブプロセスとバウンダリイベントを使用した高度なプロセスのサンプルです。

**プロセスの流れ:**

- **メインフロー**: データ準備 → メイン処理 → 結果確認
- **エラー処理サブプロセス**: エラー発生時にエラーログ記録と通知
- **定期実行サブプロセス**: 5分毎に進捗確認（非中断）
- **キャンセル処理サブプロセス**: キャンセル要求時に処理中断とロールバック
- **バウンダリイベント**: メイン処理のタイムアウト（30分）

**学べる要素:**

- イベントサブプロセス（triggeredByEvent="true"）
- エラーイベント、タイマーイベント、メッセージイベント
- バウンダリイベント（タイムアウト）
- 中断型と非中断型のイベント
- 終了イベント（terminateEventDefinition）

## BPMN の基本要素

### イベント

- **開始イベント** (○): プロセスの開始点
- **終了イベント** (◎): プロセスの終了点
- **中間イベント**: プロセス中に発生するイベント

### アクティビティ

- **タスク** (□): 実行する作業
- **サブプロセス**: 複数のタスクをまとめたもの

### ゲートウェイ

- **排他ゲートウェイ** (◇): 条件分岐（1つの経路を選択）
- **並行ゲートウェイ** (◇+): 並行処理（複数の経路を同時実行）

### フロー

- **シーケンスフロー** (→): タスク間の流れ
- **メッセージフロー** (⤏): プール間のメッセージ

## BPMN ファイルの作成

BPMN ファイルは、以下のツールで作成できます：

- [bpmn.io](https://bpmn.io/) - オープンソースのBPMNモデリングツール
- [Camunda Modeler](https://camunda.com/download/modeler/) - 無料のBPMNモデリングツール
- [Activiti Modeler](https://www.activiti.org/) - オープンソースのワークフローエンジン付属のモデラー
